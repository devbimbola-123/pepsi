URBAN LUXE — FASHION STORE WEBSITE

FILES
- index.html: page structure and Bootstrap links
- style.css: all custom styling and responsive layout
- script.js: product filters, demo shopping bag, newsletter response
- README.txt: this guide

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Internet is needed for Bootstrap, Google Fonts, and the Unsplash demo photos.

BEFORE YOU LAUNCH
- Replace demo product photos, names, and prices with your real inventory.
- Replace the Urban Luxe brand name with your store name if needed.
- Add your real WhatsApp number, delivery details, social links and contact email.
- The cart and newsletter are front-end demos only. Checkout/payment and subscription storage are not connected. Connect a payment provider or order workflow before accepting real orders.
- Product photo URLs are loaded from Unsplash and require internet access.
